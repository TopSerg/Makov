# Makov — интерактивное генеалогическое древо

Готовый проект для Netlify + Supabase.

## Развёртывание

1. Импортируйте репозиторий в Netlify.
2. Добавьте переменные окружения:
   - `SUPABASE_URL`
   - `SUPABASE_PUBLISHABLE_KEY`
3. Выполните Deploy.

Frontend публикуется из `public/`, Netlify Functions находятся в `netlify/functions/`.
